# TunnelApp

> แอปพลิเคชันแสดงผลสถานะและระดับน้ำในอุโมงค์ทางลอดแบบเรียลไทม์ โดยเชื่อมต่อข้อมูลจากเซนเซอร์ตรวจวัดผ่านฐานข้อมูลคลาวด์ เพื่อแจ้งเตือนภัยน้ำท่วมในอุโมงค์ทางลอดล่วงหน้า

---

## 🌊 เกณฑ์การวัดระดับน้ำและการแจ้งเตือน (Water Level Thresholds)

ระบบใช้เซนเซอร์อัลตราโซนิกในการตรวจวัดระดับน้ำ โดยแบ่งเกณฑ์สถานะออกเป็น 3 ระดับ

| ระดับสถานะ | ค่าระดับน้ำที่วัดได้ | รายละเอียด / การทำงานของระบบ |
| :--- | :--- | :--- |
| 🟢 **ปลอดภัย** | 0 – 2.9 เซนติเมตร | สภาพการจราจรในอุโมงค์ปกติ เปิดให้สัญจรได้ |
| 🟡 **ระวัง** | 3 – 4.9 เซนติเมตร | เฝ้าระวังระดับน้ำที่กำลังเพิ่มขึ้น |
| 🔴 **อันตราย** | 5 เซนติเมตร ขึ้นไป | ระบบดำเนินการปิดอุโมงค์และแจ้งเตือนทันที |

### กลไกความปลอดภัยอัตโนมัติเมื่อระดับน้ำเกินกำหนด 
เมื่อเซนเซอร์ตรวจพบระดับน้ำในเกณฑ์อันตราย ระบบจะเข้าสู่โหมดฉุกเฉินและทำการ:
1. **ส่งสัญญาณเสียงแจ้งเตือน 3 ครั้ง** ผ่าน Buzzer/ลำโพงเตือนภัย
2. **สั่งปิดไม้กั้นทางเข้าอุโมงค์อัตโนมัติ** เพื่อป้องกันไม่ให้ยานพาหนะผ่านเข้าไป
3. **ไฟสถานะ RGB** แสดงสีแจ้งเตือนสถานะอันตรายอย่างชัดเจน

## 📱 ฟังก์ชันและหน้าจอการใช้งาน (Application Features)

### 1. หน้าหลัก 
- แสดงข้อมูลพิกัดและแผนที่ตำแหน่งที่ตั้ง
- แสดงรายงานสภาพอากาศแบบ Real-time ประกอบด้วย:
  - สภาพอากาศโดยรวม (Weather Conditions)
  - อุณหภูมิ (°C)
  - ความเร็วลม (Wind Speed)
  - ความชื้นสัมพัทธ์ (Relative Humidity)
  - ระดับดัชนีแสง UV (UV Index)

### 2. หน้าอุโมงค์ (Tunnel Monitoring Dashboard)
- แผนที่แสดงตำแหน่งอุโมงค์และจุดตรวจวัด
- **Dashboard แสดงปริมาตรและระดับน้ำ:**
  - แสดงสถานะความปลอดภัยปัจจุบัน (ปลอดภัย / ระวัง / อันตราย)
  - แสดงค่าปริมาตรน้ำแบบเรียลไทม์
- **กราฟแท่ง (Trend Chart):** แสดงแนวโน้มและประวัติการเปลี่ยนแปลงของปริมาตรน้ำตามช่วงเวลา เพื่อช่วยในการวิเคราะห์และประเมินสถานการณ์
